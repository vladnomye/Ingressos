# Módulo 0002

## Requerimentos
- Usar variáveis de ambiente no projeto.

## Problemas
- Incapacidade de acessa-las sem uso de bibliotecas externas.

## Decisões
- Instalar biblioteca amplamente conhecida, *'vluvas/dtoenv'*, e por meio desta, acessar variáveis de ambiente presentes no '.env'. 

## Observações
- Tentei antes do uso da biblioteca, usar apenas funções base do próprio php, como: $_SERVER, getenv() etc...
Nenhuma dessas tentivas funcionou de fato, existe a possibilidade de se adicionar a variável direto no dockerfile por meio 
de arg e env, mas a longo prazo torna-se extremamente obsoleto, por isso decidi por meio de pesquisas sobre meios de se usar
uma variável de ambiente presente no .env, usar esta biblioteca descrita na ADR.
