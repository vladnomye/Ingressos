# Módulo 0000 ***(Obrigatório)***

## Requerimentos ***(Obrigatório)***
- Criar um modelo para futuros *diario-travamentos*.

## Problemas ***(Obrigatório)***
- Dificuldade para decidir o que estará no modelo.

## Decisões ***(Obrigatório)***
- Usar o mesmo modelo (com poucas modificações), como base para todas as documentações(*Diários* e *ADR*).  

## Observações *(Opcional)*
- Modelo pode ter seu formato alterado, nesse caso, um *ADR* deverá ser criado, explicando problemas que criaram a necessidade do novo modelo.
