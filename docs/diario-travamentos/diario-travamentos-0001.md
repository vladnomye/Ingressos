# Módulo 0001

## Requerimentos
- Testar minhas rotas usando curl -i

## Problemas
- Dificuldade para se usar o curl.

## Decisões
- Pesquisar sobre em forúms como o 'Stack Overflow'. 

## Observações
- O curl em si não é difícil de se entender, mas se você apenas executa comandos automaticamente ao invés de pensar 
racionalmente do porque precisa executa-los, vai acabar se deparando com uma parede de, um erro 'inesperado'.
Em suma, tentei mandar uma requisão curl, dentro do meu container docker, obviamente, não funcionou, visto que 
quando se cria um container, se está adicionando a aplicação do container á uma porta determinada do seu servidor,
ou seja, *fora do docker*, foi bem óbvio uma vez que vi a explicação.
